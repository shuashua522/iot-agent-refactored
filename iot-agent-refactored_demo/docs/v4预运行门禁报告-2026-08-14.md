## 仍未满足

- 两位真实人工独立标注、分歧裁决和 Cohen's kappa 仍为 pending：`13/13` 场景未完成，κ 为 `null`，不能自动填充。这是当前唯一阻止 2100-unit behavioral matrix 启动的门禁。
- 人工标注状态机已加固：若两位标注者有分歧但第三方裁决信息不完整，状态必须为 `pending_adjudication`；即使状态字段异常写成 complete，只要 κ 为空、pending 非零或仍有待裁决项，统一 readiness 也不会放行。
- 统一 readiness 现在同时读取 annotation agreement、70-unit preflight audit 和 post-commit freeze audit；只有三项全部通过才输出 `engineering_ready_for_formal_run`。当前机器可读状态为 `engineering_ready_but_annotation_blocked`，唯一 blocker 为 `complete_real_human_annotation_and_adjudication`。
- 研究者随后临时接受两个独立模型标注与第三模型裁决用于实验执行。LLM-assisted 审计覆盖 `13/13` 场景，原始一致率 `61.54%`、schema 归一化后语义一致率 `84.62%`、model-model κ=`0.5455`。readiness 只有显式启用 `--allow-llm-assisted-annotation` 才可解除执行阻塞；真实人工 κ 仍为 `null`，必须作为协议偏离披露。
- 历史状态：截至 2026-08-14 本报告生成时，2100-unit 主矩阵、210-unit longitudinal、28-unit robustness 尚未运行；它们已于 2026-08-15 完成。

## 预算与命令

基于本次 70-unit preflight 的真实用量，2100-unit主矩阵预计约 `2520` 次 API 调用、`14,544,930` prompt tokens、`148,530` completion tokens、`14,693,460` total tokens。该估计取代旧的约 436 万 token 外推，但仍不是费用承诺。正式运行应使用 `--resume`，先低并发，稳定后逐步增加；每批不超过 200 次 API 调用，批后检查 strict/trace audit 和成本。transport failure 只按预注册策略有限重试，模型行为失败不得为了改善结果而重跑。

人工标注完成方式：两位标注者独立填写 `experiments/annotations/protocol_v4/inter_annotator/*.json`，不得查看模型 trace 或对方标签；分歧由第三人裁决。随后运行：

```bash
PYTHONDONTWRITEBYTECODE=1 python3 experiments/scripts/compute_annotation_agreement.py \
  --annotation-root experiments/annotations/protocol_v4/inter_annotator \
  --output experiments/annotations/protocol_v4/annotation_agreement.json
```

```bash
PYTHONDONTWRITEBYTECODE=1 python3 experiments/scripts/seal_protocol_v4_freeze.py \
  --output experiments/results/protocol_v4_pre_run_20260814/reports/freeze_receipt.json
PYTHONDONTWRITEBYTECODE=1 python3 experiments/scripts/audit_protocol_v4_freeze.py \
```
