因此当前 `experiments/memory/vector_index.py` 采用了依赖无关的词项重叠检索 fallback。

这能保证：

- 实验主线可以先跑起来
- 不会因为缺少外部依赖而完全阻塞

后续建议：

- 若环境允许，再补真正的 Chroma adapter
- 保留当前 fallback 作为无依赖 smoke path

### 2. `PyYAML` 不在当前环境

因此当前场景文件采用：
