### 2. 记忆核心第一版

已实现：

- `MemoryRecord` / `MemoryEdge` / `UsageEvent` / `SearchResultPackage`
- SQLite canonical store
- 置信度与 `effective_confidence`
- 基础生命周期刷新
- `usable-stale` 的 query / 澄清运行时区分
- stale 记忆在成功验证后的 `active` 回迁
- candidate 晋升的 7 天窗口 / 无反例计数语义
- `SearchResultPackage.global_constraints` 现已会携带 preference / routine / reflection 约束记忆
- 基于关系链的负向 ripple 基础传播（1 跳 `0.3`、2 跳 `0.09`、3 跳截断）
- `split` 的基础 lineage / edge 落盘（`supersedes`、`derived_from_memory_ids`、specialize/generalize edge）
- `merge` 的 `coverage_proof + evidence_refs` 并集保留
- `resampling` 现已会保留 `resampled_from` / `resampled_at` 等可追溯字段
- 依赖无外部向量库的检索 fallback
- merge 的 `coverage_proof` 现已会自动补全 `sources`，缺失或不完整时会在维护阶段触发 rollback
- 基础 memory service：
  - `apply_memory_op`
  - `search`
  - `mark_outcome`
  - `maintenance`
