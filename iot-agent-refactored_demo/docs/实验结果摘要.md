## 5. 当前结论

- 截至 Monday, August 10, 2026，实验主线已经可以运行 `Ours / baseline / ablation` 三类系统。
- `Estimated Prompt Tokens` / `Estimated Maintenance Tokens` 是确定性 proxy，不是真实 LLM API token usage。
- 自动化工件审计状态：`pass`；可确认范围：`oracle_only`。
- 目前结果仍属于开发态结果，主要用于验证主线、场景和统计链路是否成立。

### v4 预运行新增 pilot（2026-08-14）

- 仅完成两条新增真实 external-LLM 行为 trace：`Ours/Q1_v4_behavioral/1001` 成功（1,375 total tokens）和第二家庭 `Ours/B6W_v4_robustness/1001` 成功（1,407 total tokens）。两者均为 1 次 API 调用、无 fallback 或 transport failure，trace audit 为 `2/2`。
- 这两条 trace 没有 Ours-vs-baseline 的配对比较，也没有覆盖冻结主行为矩阵的 `2100` units，正式统计状态只能为 `descriptive_only`，不能写为论文主实验、显著性结果或泛化证据。
- Q1 pilot 的原始模型行为有效，但生成时存在 runner evaluator bug：`memory.answer` 被标为 action 而非 query，故旧聚合中的 `Query Answer Accuracy` 为缺失。该 bug 已由本地回归修复；历史 trace 不重写、不补跑，且不进入正式指标表。

### v4 最终统计与执行门禁（2026-08-14）

- 正式统计已改为 scenario×replicate_id 配对、两层 clustered bootstrap、exact McNemar、连续指标 paired sign-flip 和全预注册 primary metrics 的 Holm correction；所有差值采用 Ours-minus-baseline，方向归一化 effect 的正值统一表示 Ours 更优。
- transport failure、fallback、no-agent-call、真实模型行为失败和指标不适用现在分开记录。模型输出解析失败保留为性能失败，不再被错误排除。
- raw/guarded accuracy 与 override 分类已按每个 decision 的 evaluator 外部真值计算；仅 reason 改写不计作 override。
- HAOracle 已补 service、参数、capability 与范围门禁。本地 `112/112` smoke 通过，hidden bridge、baseline fidelity、ingestion、longitudinal 零成本审计通过。
- 新 API `newapi / gpt-5.4-mini` probe 已成功，provider seed 可用。冻结 revision `8c4390c` 上的 70-unit preflight 已完成：`70/70` 落盘、`70/70` trace audit 通过、零 transport/fallback/usage missing/指标异常，B1/B4 fidelity 通过，工程状态为 `engineering_ready_for_formal_run`。
- preflight 使用 `84` 次 API 调用与 `489782` total tokens；正式 2100-unit behavioral matrix 最新外推约为 `2520` 次 API 调用与 `14693460` total tokens。preflight 只有一个 replicate，统计状态仍为 `descriptive_only`，不能写作显著性或论文最终主结果。
- preflight 中 Ours 相对 B0-B5 的 TSR 差值依次为 `+0.5/+0.5/+0.2/0.0/+0.5/+0.1`。raw/guarded planner accuracy 为 `53.57%/58.33%`，8 次 override 中 4 次 corrected、0 次 harmful、4 次 neutral；这些只用于验证指标和 guard 诊断链路。
- 当前唯一正式启动阻塞为真实人工双标注、分歧裁决与 Cohen's κ：`13/13` 场景待标注、κ 为 `null`。正式 behavioral matrix 测量的是 experiments MemoryService + plan-only Agent adapter，不代表完整 smartHome 产品运行时。
- 正式启动门禁已改为机器可读的三项合取：annotation 必须 complete、无 pending/待裁决且 κ 非空，70-unit preflight 必须为 `engineering_ready_for_formal_run`，post-commit freeze 必须 pass。当前统一 readiness 为 `engineering_ready_but_annotation_blocked`，不会因旧 pilot 状态或未裁决分歧误启动正式矩阵。
- 研究者已临时接受 `2 个独立模型标注 + 第 3 模型裁决` 用于解除实验执行阻塞：覆盖 `13/13` 场景，原始完全一致率 `61.54%`，schema 归一化后语义一致率 `84.62%`，model-model Cohen's κ=`0.5455`。该值不是 human κ；正式结果与论文方法必须披露 `complete_llm_assisted` 协议偏离，后续仍需真实人工复核。
